# Italiano do Zero ao C2

Aplicativo web estático para organizar um curso autodidata de italiano alinhado ao CEFR. Ele oferece um sumário interativo com capítulos estruturados do nível A1 ao C2, incluindo objetivos, vocabulário, gramática, diálogos, exercícios, gabaritos e dicas culturais.

## Como usar

1. Abra `index.html` em um navegador moderno.
2. Clique em **Entrar** para criar uma sessão local (nome + email) e liberar salvamento automático das preferências.
3. Use o menu de níveis para expandir cada capítulo.
4. Abra **Configurações** (ícone de engrenagem) para ativar o modo escuro e ajustar o tamanho do texto.
5. Siga as instruções de estudo, exercícios e revisões.

## Estrutura do projeto

- `index.html` — página principal com todo o conteúdo do curso.
- `styles.css` — estilos visuais responsivos, topbar com sessão, modais e modo escuro.
- `script.js` — acordeões, gerenciamento de sessão local (login/logout) e persistência de preferências (tema e fonte).

## Créditos

Conteúdo pedagógico fornecido pelo solicitante. Layout desenvolvido para facilitar o estudo autodidata.
